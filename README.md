# Trip Talk

旅行英会話の予習と、ChatGPT Liveへ渡すロールプレイ指示書を作るiPhone向けWebアプリです。

## 現在の学習内容

- タモやん：ホテル内の5場面
- ちゃみ：空港到着後の3場面
- 場面別の自然な会話例
- 相手のセリフに自分で答えてから回答例を表示
- 重要表現と必須語彙の意味をタップで確認
- 会話例、場面、難易度を反映したChatGPT Live用指示書

アプリ内の有料Realtime会話は現在凍結しています。音声練習は、指示書を各自のChatGPTへ貼り付けて行います。

## ローカル起動

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。現在の主要フローにはOpenAI APIキーは不要です。

## 確認コマンド

```bash
npm run lint
npm run build
```

## データと秘密情報

難易度設定はブラウザのローカルストレージへ利用者別に保存します。`.env.local` はGitの除外対象です。APIキーなどの秘密情報をリポジトリへコミットしないでください。

## 設計方針

- 文法レベルだけで内容を制限せず、その場面で普通に必要な語彙と言い回しを扱う
- 内容は現実的にし、短い文、日本語訳、回答例で学びやすくする
- 会話例は暗唱用の台本ではなく、展開と表現を理解する参考にする
- リアクション語句も会話例の自然な位置で練習する
- ChatGPT Liveは会話例を参考にしながら、利用者の返答に応じて展開を変える
- AIは習得や進級を判定せず、次へ進むかは本人が決める
