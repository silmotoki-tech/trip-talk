# Trip Talk — 開発引き継ぎの入口

更新日：2026-09-10

## 最初にここだけ読む

現在のTrip Talkは、iPhone向けの旅行英会話予習と、各自のChatGPTへ渡すロールプレイ指示書の作成アプリ。アプリ内の有料Realtimeは凍結中。API＋FirebaseでLive・分析・履歴保存を完結する構想は、実装済みではない。

2人・ホテル5場面／空港5場面を定義。利用者別の難易度と練習モードをlocalStorageへ保存する。設定の分離は認証やクラウドの履歴分離とは異なる。コードの確認基準は `6a5a8c8`（2026-09-08確認）。作業開始時に最新HEADと未コミット変更を確認する。

## 作業中に守ること

- 本人が難易度と進行を選ぶ。AIの自動進級を追加しない。
- 目標仕様と現行コード、過去の試験と今回の検証を区別する。
- APIの凍結解除やFirebase導入は別の意思決定。資料を実行許可と扱わない。
- 利用者ID・保存済みデータ・未コミット変更を保全する。全消去でテストを片付けない。
- 秘密情報や個人の会話・学習履歴を公開GitHubへ保存しない。
- コード変更前にリポジトリのAGENTS.md／CLAUDE.mdを確認する。
- GitHubへ書き込む前に、対象が `silmotoki-tech/trip-talk` であることを確認する。

更新時は、変更した分野の資料と必要なリンクだけを直す。Trip Talkと関連する別アプリTamoyan-English、院内アプリmanagement-theme-appを混同しない。
